A fortune-cookie prophecy for engineers: "You will ship on Friday. The build will pass, the servers will not, and the cookie saw it coming."

## Run it

```sh
python3 main.py
```

## Why this line

A fortune cookie speaks in prophecy, so the line opens like one —
"You will ship on Friday" — then the prophecy splits in two: the
build passes, the servers don't. The twist is the cookie itself
claiming foresight: it knew the deploy was doomed before you did.

It also stays inside the fortune-cookie form: a single sentence,
a prediction about your near future, and no explanation of why —
which is exactly how real fortune cookies deliver bad news.
